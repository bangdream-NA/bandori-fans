bandori.fans は、BanG Dream! シリーズ（バンドリ）のために生まれたファンデータベースです。ライブの完全なセットリストを調べたいとき、CD の発売予定を追いたいとき、今日がキャストの誕生日か確認したいとき、あるいは「今日は何の日」にどんな出来事があったのか知りたいとき——ここなら、すべてを一か所で確認できます。あらゆる情報が相互にリンクされているため、クリックするだけでデータの網を自由に巡れます。

## ✨ 主な特長

- **10 バンドの世界へワンクリックで没入** —— 好きなバンド（Poppin'Party、Roselia、MyGO!!!!!、Ave Mujica など）を選ぶと、サイト全体がそのバンドのブランドカラーに変わります。トップページ、ニュース、カレンダーもすべて絞り込まれ、関心のあるバンドだけを表示できます。
- **購読できるリアルタイムカレンダー** —— ライブ、イベント、CD リリースを、普段使っている Google / Apple / Outlook カレンダーへワンクリックで同期できます。自動更新されるため、チケット発売やリリースを見逃しません。
- **すべてがつながるデータネットワーク** —— 楽曲 ⇄ バンド ⇄ キャラクター ⇄ キャスト ⇄ CD ⇄ ライブ ⇄ 会場。どの項目からも関連項目へ移動でき、リンクをたどってどこまでも楽しめます。
- **3言語 + ライト／ダークテーマ** —— 简体 / 日本語 / EN を自由に切り替えられ、ライト / ダーク / システム設定に追従から選択できます。選択内容は保存されます。
- **誰でも参加可能** —— 間違いを見つけたら、どなたでもオンラインで訂正を送れます。サイトはファン有志による共同運営で、非営利・非公式です。

## 🏠 トップページ

トップページを開くと、次の内容が表示されます。

- **リアルタイムステータスバー**：ページ最上部に、点滅する小さなドットと「リアルタイム」の表示があり、データがいつまで更新されているかを示します（例：「データバージョン v 2026-06-24 15:34 JST」）。右側では言語とテーマを切り替えられます。
- **サイトロゴエリア**：大きな「BANDORi.FANS」ロゴ、短いサイト紹介、そして**サイト内検索ボックス**（`Ctrl K` / `⌘ K` で呼び出し可能）があります。
- **バンドカラースイッチャー**：「すべてのバンド」と 10 バンドが横一列に並び、それぞれの前に専用カラーの小さなドットがあります。選択するとサイト全体の色と表示内容が切り替わり、選択内容は保存されます。
- **今日の記念日カード**（// TODAY IN BANDORI）：今日の日付と、「今日は何の日」に該当する記念イベント（キャストの誕生日、アルバム発売記念日、イベント記念日など）を表示します。各行には年とバンドタグが付きます。
- **次回公演 Hero**（NEXT LIVE）：バンドのテーマカラーを背景にした大きなカードで、次回公演のタイトル、日付、会場、地域を表示します。「ライブ詳細を見る →」からワンクリックで移動できます。
- **近日予定カレンダー**（UPCOMING）：今日から約 2 週間分の予定を横長の日付帯で表示します。当日は強調され、ライブやリリースは小さな色付きブロックで示されます。
- **その他のセクションカード**：最新ニュース、近日公演、リリース、サブデータベース索引の 4 枚のショートカットカードです。それぞれリアルタイムの件数を表示し、クリックすると直接移動できます。

## 📰 ニュース

BanG Dream! シリーズ全体の公式情報とコミュニティ情報をまとめて追跡できます。

- **注目ニュースバナー**：選りすぐりの 3 件を、画像、バンドタグ、タイトル、日付付きの大型カードで表示します。
- **多角的な絞り込み（併用可能）**：**情報源**（公式 / Bushiroad / Twitter / その他）、**期間**（直近 7 / 30 / 90 日）、**種類**（音楽 / メディア / BanG Dream! TV / ライブ情報 / グッズ / プレイリスト / オフラインイベント / チケットなど）、**バンド**で絞り込めます。いずれかの条件が有効なときは、「絞り込みをリセット ↺」で一括解除できます。
- **ニュース一覧**：日付、種類、バンド、タイトル（一部は概要付き）、情報源バッジを各行に表示し、ページ送りにも対応します。
- **ニュース詳細**：本文／概要、公開日と更新日、情報源、関連リンク、関連スケジュール（カレンダー内の該当イベントへ移動可能）を表示します。ページ下部の「元の情報源で見る ↗」から公式サイトや投稿へ直接移動でき、同じバンドの他のニュースも紹介します。

## 📅 カレンダーと購読

ライブ、イベント、リリースを一つのページで確認し、自分のカレンダーへ同期できます。

- **カレンダー購読**：購読リンク（「コピー」でワンクリックコピー）と、「Google カレンダー ↗」「Apple カレンダー ↗」「Outlook ↗」の 3 つの追加ボタンを用意し、手順付きの「追加方法」も掲載しています。内容は自動更新されます。バンドで絞り込むと、そのバンド専用の購読フィードになります（例：「Roselia のカレンダーを購読」）。
- **3 つの表示形式**：月間カレンダー、チケット（今後のチケット販売スケジュール）、リスト（今後のイベント予定）があります。
- **カテゴリ絞り込み**：すべて / ライブ / イベント / リリース / チケット販売 / トーク / ファンミーティング / 展示 / 店舗イベント / ポップアップストア / コラボカフェ。カテゴリごとに色分けされます。
- **月の移動**：前月 / 今日 / 翌月 + 年月セレクター。移動しても、バンド、カテゴリ、表示形式の選択は保持されます。
- **月表示（デスクトップ）**：7 列の週グリッドで、今日を強調表示します。イベントが多い日は「+N 件」から展開できます。中止イベントには印と取り消し線が付きます。上部の「チケット販売期間」パネルには、その月の販売期間が 1 件ずつ表示されます。
- **モバイル**：縦型の「スケジュール」リストへ切り替わり、予定のある日だけを表示します。「今月のチケット販売期間」セクションもあります。

## 🎂 今日の記念日

トップページのカードより詳しい、独立した「今日は何の日？」ページです。上部に日付カード（東京タイムゾーン）があり、その下に固定の 5 つの「今日は何の日」カテゴリがあります。

- **バンド記念日 ★** —— 今日デビュー／結成したバンド（「N 周年」表示付き）
- **キャストの誕生日 ☆** —— 今日が誕生日のキャスト（プライバシーに配慮し、年齢は表示しません）
- **音源リリース記念日 ◇** —— 過去の今日に発売された音源
- **ライブ記念日 ●** —— 過去の今日に開催されたライブ
- **ニュース記念日 ▣** —— 過去の今日に公開されたニュース

各項目には年、バンドタグ、クリック可能なタイトルが付き、対応する詳細ページへ直接移動できます。今日の 5 カテゴリがすべて空の場合は、「明日のプレビュー」と「直近 7 日間の振り返り」を表示します。

## 🗂️ データベース

「データベース」索引ページには、相互リンクされた **6 つのサブデータベース**が集約されています。各カードにはリアルタイムの件数が表示されます。すべての一覧ページで、ページ送り、昇順／降順の並べ替え、バンドでの絞り込み、「絞り込みを解除」を利用できます。

### 🎤 ライブ・イベント
- **一覧**：日付、タイトル（縦長ポスターのサムネイル付き）、バンド、会場、記録（公演数／楽曲数／出演者数）を公演ごとに表示します。「開催予定 / 終了済み」とバンドで絞り込めます。中止公演には取り消し線付きバッジが表示されます。複数日にわたるツアーは、公演日ごとに 1 行を使用します。
- **詳細**：横長のキービジュアルと日付、会場、公式ページを表示します。**セットリスト / SETLIST**（各曲に番号と歌唱バンドのカラーバッジが付き、楽曲ページへ移動可能。複数公演のツアーは公演別にグループ化）、**関連ニュース**、**出演者**（出演 / 共演 / 楽曲歌唱 / 関連）を掲載します。複数会場のツアーには**ツアー会場**も表示されます。

### 🎵 楽曲
- **一覧**：タイトル（ローマ字表記付き）、所属バンド（ブランドカラーのタグ）、リリース日、収録先（CD ページへ移動可能）、番号、公演数／トラック数を表示します。
- **詳細**：楽曲名とローマ字表記、**曲名の別表記**（別名／ローカライズ名／多言語名）、リリース日／長さ／番号／歌唱者を表示します。バンド、**収録 CD**、**ライブ演奏履歴**へ相互に移動できます。

### 🎸 バンド
- **一覧**：10 枚のバンドカード（Logo / バンド名 / ローマ字表記 + メンバー数／楽曲数／公演数）を表示し、「活動中 / 解散済み」で絞り込めます。
- **詳細**：ページ全体がそのバンドのカラーに変わり、Hero に Logo を表示します。デビュー日、メンバー数、活動状態、別名、シリーズなどの情報を掲載します。時代ごとに編成が異なる場合は、「編成時代」のアコーディオンがあります。相互リンクエリアには、メンバー、楽曲、ライブ、ニュース、キャラクター、CD 作品、ライブのセットリストを掲載します。

### 👤 キャラクター
- **一覧**：キャラクターのアイコンカード（キャラクター名 / 所属バンド / CV キャスト名）を表示し、バンドで絞り込めます。
- **詳細**：キャラクターの立ち絵 Hero と名前の読み方を表示します。クリック可能なバンドタグとキャストタグがあります。バンドメンバーの場合は、担当（楽器パート）、誕生日、星座、血液型、身長、スリーサイズ、イメージカラーなども掲載します。**歴代キャスト**、**ライブでの歌唱楽曲**、年ごとに折りたためる**出演履歴**、ソーシャルアカウントも確認できます。

### 🎙️ キャスト
- **一覧**：まず「バンド別に見る」の概要（各バンドのキャスト数付き）を表示し、選択すると写真、氏名、読み方、CV を担当するキャラクター名を表示します。
- **詳細**：キャスト写真の Hero、読み方、誕生日（クリックすると「今日の記念日」の該当日へ移動可能）を表示します。ソーシャルアカウントと**担当キャラクター**（キャラクター名 / 所属バンド / 担当期間、現役には印付き）も掲載します。

### 📍 会場
- **一覧**：名称、国／地域、都市、記録（イベント数／公演数）を表示します。所在地が未確認の場合は「未確認」バッジが付き、国／地域で絞り込めます。
- **詳細**：国／地域、都市、住所、**近日公演**（クリック可能）を表示します。

### 💿 CD / 音源リリース
- **一覧**：リリース日、バンド（ブランドカラーのタグ）、品番、音源名（ジャケットのサムネイル付き）、種類、ステータスを各行に表示し、「N 曲」「N 形態」のバッジが付きます。種類（アルバム／シングル／ベスト盤）、バンド、年を組み合わせて絞り込めます（条件は URL に反映され、ブックマークや共有が可能）。発売日未定の場合は、架空の日付ではなく公式の予定表記（例：「2026年秋リリース予定」）をそのまま表示します。
- **詳細**：大きなジャケット画像、タイトル、種類バッジ、品番を表示します。リリース日（その日のカレンダーへ移動可能）、参加バンド、特典がある場合は「初回限定特典」も掲載します。中心となるのは**形態別アコーディオン**です。各形態に品番、仕様（例：「Blu-ray 付」）、価格、「公式ページ ↗」を表示し、展開すると Disc ごとにグループ化された収録曲を確認できます。

> 6 つのサブデータベースはすべて相互につながっています：楽曲 ⇄ バンド ⇄ キャラクター ⇄ キャスト ⇄ CD ⇄ ライブ ⇄ 会場。どこから入ってもリンクをたどって自由に巡れます。

## 🔍 サイト内検索 & ランダム探索

- **サイト内検索**：複数カテゴリ（バンド、楽曲、キャスト、キャラクター、イベント、会場、音源、メンバー）を横断してあいまい検索し、結果をカテゴリ別に表示します。どのページでも `Ctrl K` / `⌘ K` でいつでも呼び出せます。
- **ランダム項目 ↗**：ランダムなデータ詳細ページへワンクリックで移動します。気軽に巡ったり、新しい情報を見つけたりするのに最適です。

## 🤝 共同運営への参加 / 訂正の送信

情報の誤りを見つけましたか？どなたでもオンラインで訂正を報告できます。

- **訂正フォーム**：各項目の「訂正」入口から開くと、報告対象が自動入力されます。ページ URL を手動で貼り付けることもできます。「問題の種類」「対象フィールド」を選択でき、「正しい内容」は必須です。情報源 URL、補足説明、連絡先は任意です。
- **その他の入口**：フッターには、**項目編集ガイド**（ネタバレを避ける、公式情報源を明記する、非商用、プライバシーを尊重する、中立性を保つ）、**お問い合わせ**、**更新履歴**もあります。

## 🌐 多言語とライト／ダークテーマ

- **3言語切り替え**：トップバーの「简体 | 日本語 | EN」から切り替えられます。言語を切り替えても、**現在のページと絞り込み条件は維持され**、トップページへ戻されることはありません。
- **ライト／ダークテーマ**：テーマボタンは、**ライト → ダーク → システム設定に追従**の順で切り替わります（☀ / ☾ / ⌬）。選択内容は保存されます。
