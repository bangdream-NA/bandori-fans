# Contributing

Thanks for your interest in bandori.fans! This page explains which entry point to use for different kinds of contributions.

## Reporting Bugs / Suggesting Features / Submitting Data Corrections (Repository Issues)

- 🐛 [Bug Report](../../issues/new?template=bug_report_en.yml) — reproducible issues with site pages, interactions, display, search, or calendar subscriptions.
- ✨ [Feature Request](../../issues/new?template=feature_request_en.yml)
- 📋 [Data Correction (Issue form)](../../issues/new?template=data_correction_en.yml) — structural or bulk data issues, or when the in-site form isn't convenient.

All three forms above are also available in `zh`/`ja`; pick your language when opening a new Issue.

## Correcting a Specific Database Entry (In-Site Form)

If only a single entry's content is wrong (a setlist, release date, venue information, etc.), we recommend using the in-site **[Correction Form](https://bandori.fans/en/contribute/fix)** instead — opening it from any entry page's "Correction" link automatically fills in the reported item, which is more efficient to process.

## Collaboration Guidelines

Whichever entry point you contribute through, please first read the in-site **[Entry Editing Guide](https://bandori.fans/en/contribute/edit)** — this is the project's authoritative source for collaboration standards, covering: no spoilers, citing official sources, non-commercial use, respecting privacy, and staying neutral.

## Applying for Long-Term Collaboration

If you'd like to get involved in ongoing development and maintenance (frontend / backend / data pipeline / testing / deployment / documentation and localization, etc.), please submit a 🤝 [Contributor Application](../../issues/new?template=contributor_application_en.yml). This Issue and everything in it will be public — do not include personal contact details or submit private code / secrets / internal information; see the form's own instructions for details.

## Code of Conduct

All discussion and collaboration on this project must follow the [Code of Conduct](CODE_OF_CONDUCT.en.md).
