# Security

## Reporting a Security Vulnerability

If you discover a security vulnerability in the bandori.fans website or this repository (such as XSS, injection, authentication bypass, or exposure of sensitive data), please report it privately via this repository's **[Private Vulnerability Reporting](../../security/advisories/new)** (Security tab → "Report a vulnerability"). **Do not** disclose reproduction details, exploit payloads, or any sensitive data in a public Issue (the same reminder appears in `.github/ISSUE_TEMPLATE/bug_report_en.yml`).

We will review and respond to your report as soon as possible. Please also refrain from publicly disclosing details of an unfixed vulnerability until we have completed a fix.

## Out of Scope

For non-security issues such as display bugs, data accuracy, or feature requests, please use the [Bug Report](../../issues/new?template=bug_report.yml) or [Data Correction](../../issues/new?template=data_correction.yml) forms instead. bandori.fans is a non-commercial fan project and does not run a bug-bounty program.
